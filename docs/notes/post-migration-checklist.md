# Post-migration checklist

Run this optional review after the primary setup scripts have completed.

## Shell

- Open a new terminal window.
- Confirm startup has no warnings.
- Confirm common aliases are available.
- Confirm the prompt renders correctly.
- Confirm command history is writable.

## Development tools

- Confirm Git can read global configuration.
- Confirm commit signing works in a test repository.
- Confirm Node and package-manager versions.
- Confirm editor command-line launchers.
- Confirm container tooling starts.

## Applications

- Confirm launch-at-login choices.
- Confirm application keyboard shortcuts.
- Confirm notification settings.
- Confirm browser extensions and imports.
- Confirm screenshot destination and shortcuts.

## Data

- Compare restored document directories.
- Confirm photos and exports are present.
- Confirm repositories have expected remotes.
- Confirm no backup is the only remaining copy.
- Keep the old machine unchanged until verification ends.

## Final review

1. Restart the computer once.
2. Repeat the shell smoke test.
3. Test one signed Git commit.
4. Open one restored document.
5. Record unresolved follow-up items.
6. Retain the verified backup.
